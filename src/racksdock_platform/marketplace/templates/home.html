Every listing is measured by independent validators from inside an environment identical to yours. Badges: hardware_verified performance_qualified dedicated not_confidential.

Two ways to rent a node

VM mode vm_isolated — preferred for dedicated customer servers. You receive a fully managed-in-your-control Ubuntu environment with its own kernel, persistent encrypted storage, SSH root access, and the ability to install your own software and Docker. Validators weight these nodes at full score.

Docker mode container — preferred for fast GPU workload deployment. You deploy containers, inference endpoints or training environments quickly, with minimal startup overhead and higher resource utilization: a root container on the host's kernel with all GPUs, nested Docker inside, and the same SSH key, startup script and billing flow. Validators weight these nodes at half score.

Both modes give one tenant per physical node and the same attestation of the GPUs. Neither is confidential computing: the hosting provider could inspect your environment, as the not_confidential badge says. static_lab marks lab nodes used for workflow tests.
